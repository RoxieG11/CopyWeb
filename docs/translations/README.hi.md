## ✨ मुख्य विशेषताएं

### 1. 🎨 सुंदर और प्रीमियम डार्क इंटरफ़ेस (PyQt6)
- **आधुनिक ऑब्सीडियन थीम:** आँखों के अनुकूल, सुरुचिपूर्ण और आधुनिक रूप।
- **मल्टी-टैब डैशबोर्ड:**
  - 🚀 **डैशबोर्ड:** वास्तविक समय की गति, फ़ाइल/पेज काउंटर और त्वरित क्रियाएं।
  - ⚙️ **सेटिंग्स:** क्रॉल गहराई (0-3), संसाधन प्रकार फिल्टर और फ़ोल्डर संरचना।
  - 🕵️ **गोपनीयता और अनामी:** रोटेटिंग User-Agent, Referrer छलावरण, मानवीय देरी और प्रॉक्सी/Tor समर्थन।
  - 🔍 **खुफिया रिपोर्ट:** सर्वर इंफ्रास्ट्रक्चर, सीएमएस पहचान और सुरक्षा ऑडिट।
  - 📜 **लाइव कंसोल:** खोज और फ़िल्टर के साथ रीयल-टाइम टर्मिनल लॉग।
- **इन-ऐप बहुभाषी प्रणाली:** इंटरफ़ेस से सीधे भाषा बदलें।

### 2. ⚡ अत्यधिक तेज़ समानांतर डाउनलोड (Multi-Threaded)
- **कॉन्फ़िगर करने योग्य थ्रेड्स:** अत्यधिक तेज़ डाउनलोडिंग के लिए 1 से 64 समानांतर थ्रेड्स।
- **HTTP/2 और कनेक्शन पूल:** बिना किसी देरी के त्वरित कनेक्शन।
- **स्मार्ट डायरेक्टरी कैशिंग:** डिस्क इनपुट/आउटपुट गति को अधिकतम करता है।

### 3. 🔍 विस्तृत खुफिया जानकारी और रिपोर्ट
- **सर्वर विश्लेषण:** सर्वर आईपी, वेब सर्वर (Nginx, Apache, Cloudflare) और बैकएंड इंजन।
- **तकनीक पहचान:** WordPress, Shopify, Next.js, React, Vue, Tailwind CSS, Bootstrap आदि।
- **स्वचालित रिपोर्ट:** स्वतंत्र `recon_report.html` और `recon_report.json` उत्पन्न करता है।

## 🚀 त्वरित शुरुआत

### विंडोज़ (Windows)
**`run.bat`** या **`WebClone.bat`** फ़ाइल पर डबल-क्लिक करें।

### लिनक्स / मैक (Linux / macOS)
```bash
git clone https://github.com/RoxieG11/CopyWeb.git
cd CopyWeb
pip install -r requirements.txt
./run.sh
# या
python3 gui.py
```
