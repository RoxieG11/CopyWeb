## ✨ Fonctionnalités Clés

### 1. 🎨 Interface Sombre & Épurée (PyQt6)
- **Thème Obsidian & Slate :** Design sombre, moderne et agréable pour les yeux.
- **Tableau de Bord Multi-Onglets :**
  - 🚀 **Aperçu Général :** Vitesse en temps réel, compteurs de fichiers/pages, indicateur de transfert et actions rapides en 1 clic (*Ouvrir le dossier*, *Prévisualisation*, *Rapport d'analyse*).
  - ⚙️ **Paramètres :** Profondeur d'exploration (0 à 3), filtres de ressources (images, CSS, scripts, polices, médias), agencement de dossiers.
  - 🕵️ **Confidentialité & Anonymat :** Rotation dynamique d'User-Agent, camouflage de Referer, simulation humaine (jitter) et support proxy/Tor.
  - 🔍 **Renseignement de Cible :** Analyse d'infrastructure serveur, détection de CMS et audit de sécurité des en-têtes.
  - 📜 **Console en Direct :** Journal interactif avec recherche et filtrage instantanés.
- **Interface Multilingue :** Changez de langue directement depuis l'application.

### 2. ⚡ Téléchargements Parallèles Ultra-Rapides
- **Pool de Threads :** De 1 à 64 threads simultanés pour exploiter pleinement votre bande passante.
- **HTTP/2 & Keep-Alive :** Réutilisation des connexions sans délai inutile.
- **Mise en Cache Intelligente :** Optimisation des entrées/sorties disque.

### 3. 🔍 Reconnaissance Approfondie et Rapports Automatiques
- **Analyse du Serveur :** IP, serveur web (Nginx, Apache, Cloudflare), détection CMS/frameworks (WordPress, Shopify, React, Vue, Next.js, Tailwind CSS).
- **Rapports Autonomes :** Génère automatiquement `recon_report.html` et `recon_report.json`.

## 🚀 Démarrage Rapide

### Windows
Double-cliquez sur **`run.bat`** ou **`WebClone.bat`**.

### Linux / macOS
```bash
git clone https://github.com/RoxieG11/CopyWeb.git
cd CopyWeb
pip install -r requirements.txt
./run.sh
# ou
python3 gui.py
```
