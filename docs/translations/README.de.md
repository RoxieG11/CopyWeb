## ✨ Hauptfunktionen

### 1. 🎨 Elegante & Premium Dark-Benutzeroberfläche (PyQt6)
- **Obsidian & Slate Theme:** Augenfreundliches, modernes und aufgeräumtes Design.
- **Multifunktionales Dashboard:**
  - 🚀 **Übersicht:** Live-Geschwindigkeit, Datei-/Seitenzähler, Datenübertragung und Ein-Klick-Aktionen (*Ordner öffnen*, *Vorschau*, *index.html*, *Aufklärungsbericht*).
  - ⚙️ **Klon-Einstellungen:** Crawl-Tiefe (0-3), Ressourcentypen-Filter und Ordnerlayout (*Organized* / *Mirror*).
  - 🕵️ **Datenschutz & Stealth:** Dynamische User-Agent-Rotation, Referrer-Tarnung, menschliche Verzögerungen (Jitter) und Proxy-/Tor-Unterstützung.
  - 🔍 **Ziel-Aufklärung:** Serverinfrastruktur, CMS-/Framework-Erkennung und Sicherheits-Audit.
  - 📜 **Echtzeit-Konsole:** Durchsuchbares Live-Aktivitätsprotokoll.
- **Mehrsprachige Benutzeroberfläche:** Sprache direkt im Programm umschaltbar.

### 2. ⚡ Parallele Hochgeschwindigkeits-Downloads
- **Konfigurierbarer Thread-Pool:** 1 bis 64 gleichzeitige Threads für maximale Downloadraten.
- **HTTP/2 & Keep-Alive:** Wiederverwendbare Verbindungen ohne Latenz.
- **Intelligentes Verzeichnis-Caching:** Minimiert Schreib- und Lesezugriffe auf der Festplatte.

### 3. 🔍 Umfassende Zielaufklärung
- **Infrastrukturanalyse:** Server-IP, Webserver (Nginx, Apache, Cloudflare), Frameworks (React, Vue, Next.js, Tailwind CSS) und robots.txt/sitemap.xml.
- **Automatische Berichte:** Generiert eigenständige `recon_report.html` und `recon_report.json` Berichte.

## 🚀 Schnellstart

### Windows
Doppelklicken Sie auf die Datei **`run.bat`** oder **`WebClone.bat`**.

### Linux / macOS
```bash
git clone https://github.com/RoxieG11/CopyWeb.git
cd CopyWeb
pip install -r requirements.txt
./run.sh
# oder
python3 gui.py
```
