## ✨ Principais Recursos

### 1. 🎨 Interface Escura Premium (PyQt6)
- **Tema Obsidian & Slate:** Design moderno, limpo e suave aos olhos.
- **Painel com Múltiplas Abas:**
  - 🚀 **Painel Principal:** Indicadores de velocidade em tempo real, contadores de páginas e arquivos, e ações rápidas com um clique.
  - ⚙️ **Configurações:** Profundidade de links (0 a 3), filtros de tipos de recursos (imagens, estilos, scripts) e layout de pastas.
  - 🕵️ **Privacidade & Sigilo:** Rotação dinâmica de User-Agent, camuflagem de Referer e suporte a proxy/Tor.
  - 🔍 **Reconhecimento:** Análise de infraestrutura do servidor, detecção de CMS e auditoria de cabeçalhos de segurança.
  - 📜 **Console em Tempo Real:** Log detalhado com pesquisa e filtragem instantânea.
- **Suporte Multilíngue Integrado:** Alterne de idioma diretamente pela interface do aplicativo.

### 2. ⚡ Downloads Paralelos Ultrarrápidos
- **Pool de Threads:** De 1 a 64 threads simultâneas para download acelerado de recursos.
- **HTTP/2 e Sessões Persistentes:** Conexões reutilizáveis sem latência desnecessária.
- **Cache Inteligente de Diretórios:** Otimização de leitura e escrita em disco.

### 3. 🔍 Reconhecimento Profundo e Relatórios
- **Análise do Alvo:** IP do servidor, software web (Nginx, Apache, Cloudflare), CMS (WordPress, Shopify) e bibliotecas (React, Vue, Tailwind CSS).
- **Relatórios Automáticos:** Geração automática de `recon_report.html` e `recon_report.json`.

## 🚀 Início Rápido

### Windows
Dê um duplo clique no arquivo **`run.bat`** ou **`WebClone.bat`**.

### Linux / macOS
```bash
git clone https://github.com/RoxieG11/CopyWeb.git
cd CopyWeb
pip install -r requirements.txt
./run.sh
# ou
python3 gui.py
```
